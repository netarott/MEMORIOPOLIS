# Chapter 04: The Translator

『記憶都市（メモリオポリス）』第四章「翻訳者」で使用したPython模型です。

## Models

### Section 07: Moving the Arrows

証拠を履歴として保持し、保存済みの履歴に基づいて状態を再計算する最小状態機械です。

### Section 08: The Same Three Hours

最終回答までの時間が同じでも、途中で観測可能になった履歴が異なる二つのシナリオを比較します。

### Section 08: The Thickness of Time, Refined Experiment v2

内部履歴、可視履歴、最終回答前の可視応答、最長可視沈黙を分離します。

The models use synthetic data only.

These models are not intended for employee ranking, disciplinary decisions, or performance evaluation.
