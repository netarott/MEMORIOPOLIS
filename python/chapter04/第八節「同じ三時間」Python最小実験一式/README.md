# 第八節「時間の厚み」最小実験

## 問い

二つの対象が、どちらも未確定に3時間いた。

- A：最終回答まで途中の応答がない。
- B：思考時間は同じだが、受領・確認開始・中間状況を段階的に共有する。

時計上の3時間は同じでも、観測された履歴と最初の応答時間は同じか。

## 実行

```powershell
python .\section8_time_model.py `
    --input .\time_events.csv `
    --output-dir .\results
```

外部ライブラリは不要。Python 3.10以上を想定。

## 変数

- `dwell_minutes_tau`：依頼到着から最終回答までの滞在時間 \(\tau\)
- `first_response_minutes_rho`：依頼到着から最初の可視応答までの時間 \(\rho\)
- `history_count`：保存された履歴の件数
- `visible_history_count`：依頼者から観測可能な履歴の件数

## この模型が評価しないもの

- 作業者の能力
- 性格や心理
- 誰が速い・遅いか
- 処遇・懲罰

この模型は、依頼から最終回答までの間に、何が観測可能になったかだけを比較する。

## 防衛線

「レスポンス向上」を、若いメンバーから思考時間を奪う規則にしない。最終回答までの時間を保ったまま、途中状態を共有できるかを試す。
