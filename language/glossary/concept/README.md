# MEMORIOPOLIS Concept Dictionary

このフォルダは『記憶都市（メモリオポリス）』の概念辞典です。

各概念には、特定の言語に依存しない概念IDを付与します。
韓国語、英語、臺灣繁體中文、ロシア語、日本語の表現は、同じ概念IDに関連付けます。

## 基本方針

- 概念IDは `C0001` 形式で管理する。
- ファイル名は `C0001_Record.md` のように、概念IDと英語キーを組み合わせる。
- Romanization は韓国語の改訂ローマ字表記を基本とする。
- 各言語の訳語は、作品本文での用法を優先する。
- 作中例文、初出箇所、関連概念を段階的に追加する。

## 登録済み概念

- C0001 Record：記録
- C0002 Memory：記憶
- C0003 City：都市
- C0004 Notification：通知
- C0005 Reply：回信
