# MEMORIOPOLIS French Core10 draft01

## Variety
Français de France, Windows locale `fr-FR`, Anki locale `fr_FR`.

## Deck
`MEMORIOPOLIS::French`

## Note type
`MEMORIOPOLIS French Vocabulary`

## Import
Import `fr_core10_anki_draft01_18fields.csv` as UTF-8, no header, 18 columns.

## TTS
```html
{{tts fr_FR:French}}
{{tts fr_FR:ExampleFrench}}
```

Windows Basic and TextToSpeech for fr-FR are installed.

## Daily Training
After import, rebuild `JANUS-13 Daily Training`. The first filter collects due cards, and the second collects up to 10 new cards.

## AnkiDroid
If `fr_FR` does not resolve, temporarily add `{{tts-voices:}}`, copy the exact locale and voice identifier generated by AnkiDroid, and use them without normalization.

## Observation focus
Final consonants, liaison, enchaînement, nasal vowels, contractions, and the difference between written word boundaries and audible groups.
