# MEMORIOPOLIS Italian Core10 draft01

## Variety
Italiano standard, Windows locale `it-IT`, Anki locale `it_IT`.

## Deck
`MEMORIOPOLIS::Italian`

## Note type
`MEMORIOPOLIS Italian Vocabulary`

## Import
Import `it_core10_anki_draft01_18fields.csv` as UTF-8, no header, 18 columns.

## TTS
```html
{{tts it_IT:Italian}}
{{tts it_IT:ExampleItalian}}
```

Windows Basic and TextToSpeech for it-IT are installed.

## Daily Training
After import, rebuild `JANUS-13 Daily Training`. The first filter collects due cards, and the second collects up to 10 new cards.

## AnkiDroid
If `it_IT` does not resolve, temporarily add `{{tts-voices:}}`, copy the exact locale and voice identifier generated by AnkiDroid, and use them without normalization.
