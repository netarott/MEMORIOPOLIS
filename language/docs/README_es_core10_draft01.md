# MEMORIOPOLIS Spanish Core10 draft01

## Variety
Spanish (Spain), locale `es-ES`, Anki locale `es_ES`.

## Deck
`MEMORIOPOLIS::Spanish`

## Note type
`MEMORIOPOLIS Spanish Vocabulary`

## Import
Import `es_core10_anki_draft01_18fields.csv` as UTF-8, no header, 18 columns.

## TTS
```html
{{tts es_ES:Spanish}}
{{tts es_ES:ExampleSpanish}}
```

Windows `Language.Basic~~~es-ES~0.0.1.0` and `Language.TextToSpeech~~~es-ES~0.0.1.0` are already installed.

On AnkiDroid, try `es_ES` first. If a voice error occurs, temporarily add `{{tts-voices:}}`, copy the exact locale and voice identifier generated by AnkiDroid, and use them without guessing or normalizing the locale.

## Daily Training
The generic second filter `deck:MEMORIOPOLIS is:new` with a limit of 10 will collect these Spanish cards after import. Previously studied languages do not appear in that second filter because they are no longer `is:new`; due cards appear through the first filter `deck:MEMORIOPOLIS is:due` only when their due date has arrived.
