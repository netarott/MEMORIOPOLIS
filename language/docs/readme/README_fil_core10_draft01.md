# MEMORIOPOLIS Filipino Core10 draft01

## デッキ

`MEMORIOPOLIS::Filipino`

## ノートタイプ

`MEMORIOPOLIS Filipino Vocabulary`

## 位置づけ

第四章第十二節から抽出済みの共通Concept C0001～C0010を、タガログ語を基盤とする標準フィリピン語で観測する。歴史語源を詰め込まず、現代語の意味・音・用法へ櫛を通す。

## インポート

`fil_core10_anki_draft01.csv`を使用する。ヘッダーなし、UTF-8 BOM付き、16列。

## TTS

Ankiでは移植性を優先し、音声名を固定しない。PC版では音声なしの素振り、AnkiDroidで実機確認する。

```html
{{tts fil_PH:Filipino}}
{{tts fil_PH:ExampleFilipino}}
```

## 分節欄

- `PerceptualSegmentation`：学習者が音を捉えるための仮設的な区切り
- `MorphologicalBreakdown`：語根・接辞などの構造説明

両者は同一視しない。
