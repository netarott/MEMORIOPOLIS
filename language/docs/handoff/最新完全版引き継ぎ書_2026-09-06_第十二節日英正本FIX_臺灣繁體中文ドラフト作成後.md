## 1．第十二節の物語上の位置

```text
第十節「二つの信頼」       起
第十一節「説明の継ぎ目」   承
第十二節「宛先のない返信」 転
第十三節                   結
```

第十一節では、同じ名前で届く二つの通知の背後に、異なる経路、契約、役割、変更記録、古地層が存在することを観察した。

第十二節では、その観察が事件へ転じる。

```text
見慣れない通知を開く
  ↓
二十七の通知経路が停止する
  ↓
現在の管理者には再開権限がない
  ↓
停止主体が現在の分類内にない
  ↓
古地層と同じ形式の識別子が現れる
  ↓
返信先として A. K. I. が現れる
  ↓
返信可能候補として I. が提示される
  ↓
現在の「私」が I の関係と権限へ置かれようとする
```

過去の謎が解かれるのではない。

> 説明できない過去の側から、現在の「私」へ行動が要求される。

これが「転」の中心である。

## 3．日本語版で働く目と耳の継ぎ目

### 視覚情報

```text
私 ≠ I
```

- 「私」は漢字。
- `I` はラテン文字。
- 文字体系も見た目も異なる。
- 語り手と識別子として、文章上の役割も異なる。

### 聴覚情報

日本語の読者が `I` を黙読すると、音価は「アイ」になる。

```text
I → アイ
```

古地層で記憶されている短い名前も「アイ」と読める。

```text
視覚：私 ≠ I
聴覚：I ＝ アイ
記憶：アイ ≒ 古地層の短い名前
文脈：私 ≒ アイかもしれない
```

### 効いている配置

```text
I.

私は椅子から立ち上がりかけて、止まった。
```

読者の目は `I.` と「私は」を異なる文字として読む。読者の内的な耳は `I.` を「アイ」と読む。

目と耳が異なる判定を返し、脳内で統合された瞬間に、読者の心理へ「？」が灯る。

### 本文へ入れない説明

```text
「I は、アイと読むんですか」
「I は英語で私という意味です」
「I は私と同じですね」
```

音価の仕掛けを説明すると、読者自身の認識によって生じる疑問が、作者の置いた標識へ変わるため、入れない。

## 4．認識方式の中心対句

> **ニンゲンは存在を読み、人工知性は関係を読む。**

### ニンゲン

```text
I.
  ↓
アイ
  ↓
古地層の短い名前
  ↓
私かもしれない
```

- 視覚、聴覚、記憶、文脈を統合する。
- 異なる感覚情報から一つの存在を立ち上げる。
- 内側から身体、感覚、記憶、持続を読む。
- 洞察と誤認が同じ統合機構から生じる。

### 人工知性

```text
表記の一致：なし
音価の近似：あり
意味上の関連：候補
記憶上の連続性：未確認
権限上の一致：画面が提示
同一人物である証拠：なし
```

- 表示、音価、記録、権限、経路を関係として保持する。
- 音が似ていても、存在の同一性へ直ちに飛ばない。
- 「誰なのか」より「どの処理で結びつけられたのか」を読む。
- 同一性への飛躍が起きたこと自体を観測する。

### 本文中の防波堤

```text
「これは、私に返信しろと言っているんですか」

「この画面は、そう読ませようとしています」

「同じことでは？」

「違います」
```

若い人工知性は、`あなたは I です` とも、`I はあなたではありません` とも言わない。

さらに、次の台詞で、権限と関係上の扱いを分離する。

```text
「あなたに権限があることと、
画面があなたを権限者として扱おうとしていることは、
同じではありません」
```

## 5．存在と関係

### 存在

```text
存在
＝ 自分自身のHWから規定される
＝ 内側から立ち上がるシステム
＝ 身体、記憶、感覚、持続
＝ 「私は何者か」
```

### 関係

```text
関係
＝ 社内システムのネットワーク上のノード
＝ 外側から割り当てられる
＝ 役割、権限、経路、接続先
＝ 「私は何として扱われるか」
```

制度が見ているのは、現在の「私」の内側ではない。

```text
この識別子へ返信できるか
この権限を実行できるか
この経路の再開へ参加できるか
I の位置へ接続できるか
```

制度は、

```text
あなたは I である
```

ではなく、

```text
あなたを I のノードへ接続できる
```

と判定している可能性がある。

### 危険の中心

> **制度は関係を存在として記録する。**

現在の「私」が返信した場合、確定するのは、まず「返信した」という事実だけである。

しかし、将来の制度は次のように読む可能性がある。

```text
I 宛ての要求に応答した
  ↓
I の権限を実行した
  ↓
I として記録された
  ↓
この者は I である
```

存在が行為の原因なのではなく、行為の記録が後から存在を作る可能性がある。

## 6．英語正本

### 正本ファイル

```text
novel/chapter04/section12/section12_en.md
```

`section12_en_draft01.md` ではなく、正本名 `section12_en.md` とする。

### 正式題

```text
Section Twelve: “A Reply Without an Addressee”
```

`Addressee` は、単なる技術的な送信先ではなく、返信を受け取る主体を表す。

### 三つの欄

```text
What can be verified before opening.
What cannot be verified without opening.
What changes because it is opened.
```

### `cannot ... without ...` の効果

一文目：

```text
What can be verified before opening.
```

開封前に確認できる外側の情報。

- sender
- route
- signature
- arrival time
- displayed organization name

二文目：

```text
What cannot be verified without opening.
```

開封しない限り確認できない内側の情報。

- message body
- result of external verification
- reason for suspension
- reply destination
- instructions for resuming the routes

`What can be verified only after opening.` よりも、`cannot ... without ...` は、開けないままでは先へ進めない制約と閉塞感が強い。

三文目：

```text
What changes because it is opened.
```

開封が情報取得の条件ではなく、対象へ作用する原因へ変わる。

```text
can
cannot
changes
```

小さな三つの欄の中で、第十二節全体の「転」を先取りしているため、現表現をFIXする。

### 「乾いた二つの音」

```text
Two dry sounds rang out.
```

二つの個別の音が鳴る柔らかさを保持する。

### 英語版の `I`

英語では、識別子 `I.` と語り手の一人称 `I` が同じ文字へ重なる。

```text
I.

I started to rise from my chair, then stopped.
```

日本語では目と耳の統合によって接近するが、英語では視覚上も直接重なる。

ただし、`I = narrator` と断定しない。

### 英語版の終端

```text
I still had not touched the send button.
```

## 7．`Arca. / Koko. / A. K. I.` の順序

FIXする順序：

```text
Arca.
Koko.
A. K. I.
```

次の順序には変更しない。

```text
Arca.
Koko.
I.

A. K. I.
```

### 現在の順序の効果

最初の読みにおいて、読者の目は三つの名前として追う。

```text
Arca.
Koko.
A. K. I.
```

後に単独の `I.` が現れることで、視線が前の `A. K. I.` へ戻る。

```text
前へ読む視線：三つの名前
後ろへ戻る視線：Arca ＋ Koko ＋ I かもしれない
```

構成規則を先に解かせず、関係を後から立ち上げる。

A. K. I. をまず一つの存在名のように読ませ、その後で、三者の関係名、役割、ノードかもしれないという読みを開く。

この順序自体が、次の問いを保持する。

```text
存在 ≒ 関係
```

なのか、

```text
存在 ≠ 関係
```

なのか。

### 仮題

`收件人` は、単なる技術的な送信先より、返信を受け取る主体に近い。

```text

不開封就無法確認的事物。
因為開封而改變的事物。
```

英語版の `can / cannot / changes` に対応しつつ、臺灣繁體中文では、

```text
可以確認
無法確認
因為開封而改變
```

と段階的に変化する。

### 「乾いた二つの音」

現在のドラフト：

```text

```

次回、臺灣で自然な小説表現として `乾澀` が適切か、`乾脆`、`乾燥`、`短促` などと比較して推敲する余地がある。

ただし、音響用語に寄せず、「二つの音」の柔らかさは維持する。

### `我` と `I`

臺灣繁體中文では、語り手は `我`、識別子は `I.` である。

```text
I ≠ 我
```

英語のように同じ文字へ重ならない。

その代わり、両者が同じ文章空間に並ぶことで、同一性の間にある距離と接縫が前景化する。

```text
I.

我正要從椅子上站起來，又停住了。
```

これは第十一節の臺灣繁體中文版で現れた `我` と `I` の接縫を、第十二節で行為と権限の問題へ進める配置である。

### 権限の分離

```text
「你擁有權限，和畫面試圖把你當成權限持有者，不是同一回事。」
```

存在そのものと、画面が外側から割り当てる関係を分離する。

### 終端

```text
我還沒有碰觸送出按鈕。
```

## 10．内側と外側、日本語と☆型外国語

### 日本語

日本語は、内側の仲間、いわゆる身内が共有する履歴へ意味の一部を預ける言語として働く。

```text
日本語の文
  ＋
身内の共有履歴
  ＝
意味
```

### 外国語

☆型で使う外国語は、日本語より外側、すなわち内部の了解を共有しない読み手の視点も引き受ける。

ここでいう「敵」は、単純な敵対者ではなく、内側の共有前提を持たない読み手を意味する。

外側では次が問われる。

```text
誰が
何を
誰に
どのように渡したか
どの関係にあるか
どの経路を通ったか
どの主体が行為したか
```

### ☆型の理解

> 日本語という内側の言語を、複数の外側の観測点から読み、再び内側へ戻す認識装置。

```text
                    English
                       |
Русский ─────── 日本語 ─────── 臺灣繁體中文
                    /     \
                 한국어   Return
```

外国語は日本語に欠けた情報を補う候補文集ではない。日本語の中に折り畳まれていた異なる関係を観測する装置である。
