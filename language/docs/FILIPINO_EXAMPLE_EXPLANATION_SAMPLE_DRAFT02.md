# Filipino example explanation sample

## C0006 patutunguhan

### 例文

`Lumitaw sa ilalim nito ang patutunguhan ng tugon.`

### 例文の分解

- `Lumitaw` ＝ 現れた
- `sa ilalim nito` ＝ その下に
- `ang patutunguhan` ＝ 宛先が
- `ng tugon` ＝ 返信の

### なぜこの意味になるか

`lumitaw`は「現れた」です。`sa ilalim nito`では、`sa`が場所、`ilalim`が「下」、`nito`が「これ／それの」を表し、「その下に」となります。`ang patutunguhan`は現れたものとして示され、`ng tugon`が「返信の」という関係を加えます。したがって、「その下に、返信の宛先が表示された／現れた」となります。日本語訳の「表示された」は、画面上に現れたという文脈を補った表現です。
