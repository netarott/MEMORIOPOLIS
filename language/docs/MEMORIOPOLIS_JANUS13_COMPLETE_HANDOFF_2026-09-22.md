## 49．『「なむ」の来歴』から得た制作上の観測

書名：

```text
『「なむ」の来歴』
```

著者：

```text
斎藤真理子
```

### 観測した連鎖

```text
木
↓
本
↓
活字
↓
理解
↓
水
↓
夢と覚醒
↓
完全に分かったはずの真理の欠落
```

韓国語の「なむ」は木を意味する。

「本は重い。もとは木だから」という古本屋との会話では、素材としての木が、本として言葉を保持する媒体へ変わる。

夢の中では、木が本のように高速でめくれ、活字が完全に理解される。しかし覚醒時には「水って、〇〇〇なのね」の核心だけが失われる。

### MEMORIOPOLISとの接続

```text
木
→ 固定された場所・景

本
→ Novel

活字
→ Ankiカード

意味
→ Concept

夢
→ 多言語間の自由な接続

覚醒
→ 明示的に取り出せる記憶

失われた〇〇〇
→ 想起できないが知覚には残る地層
```

### ポセイドンという比喩

斎藤真理子をポセイドンと感じたのは、水の登場だけでなく、韓国、沖縄、東京、翻訳、夢、覚醒、木、本、活字の境界を横断しているため。

この比喩は人物評価の断定ではなく、制作ノート内の創作的な観測として保持する。

## 50．Concept ID、場所法、ストーリー法の実地確認

2026年9月21日のAnki学習で、Concept IDを次の二つへ同時に結びつけた。

```text
Concept ID
├─ 絵巻・都市内の固定地点
│  → 場所法
│
└─ Novel内の出来事・会話
   → ストーリー法
```

そのうえで、多言語の語形と音をAnkiで想起した。

```text
固定地点
↓
Novelの場面
↓
Concept
↓
対象言語の語形
↓
音声
```

この方法には、非常に強い手応えがあった。

### Concept IDの正式な役割

> Concept IDは、物語、絵巻、予告編、Anki、多言語、制作ノート、記憶履歴を接続する都市の住所コードである。

### 学習構造

```text
絵巻10景
→ 場所法

予告編
→ 同じ10地点の時間的巡回

Novel
→ ストーリー法

Anki
→ アクティブリコール

FSRS
→ 分散学習
```

### 実地確認により得た判断

```text
絵巻6景から10景への拡張
→ 実施する価値が高い

Concept Atlas
→ 整備すべき

Ankiの19番目の場所フィールド
→ まだ追加しない

既存のID
→ Concept Atlasの住所コードとして使用
```

## 54．フランス語で観測する項目

フランス語は、スペイン語、ブラジル・ポルトガル語、イタリア語と同じロマンス語系だが、文字と音の距離が大きい。

重点項目：

```text
語末子音の不発音
リエゾン
アンシェヌマン
鼻母音
母音字の組み合わせ
é / è / ê
ç
ch
j / g
r
性と数
冠詞
縮約
動詞活用
主語代名詞の必須性
否定構文
```

### 子音標識仮説への検査

フランス語では、子音が単語の境界を示すだけでなく、リエゾンによって次の語へ接続する。

```text
文字上の語境界
≠
音声上の語境界
```

したがって、ロシア語で生まれた子音標識仮説を修正・拡張する重要な観測面になる。

### Ankiの注目フィールド

```text
Pronunciation
→ IPAと強勢ではなく、音声連結も示す

PerceptualSegmentation
→ 書記上の語区切りと、聞こえるまとまりを区別

ExampleBreakdown
→ 語句単位の意味分解

ExampleExplanation
→ 冠詞、代名詞、縮約、語順を説明

SoundBridge
→ 不発音、リエゾン、鼻母音を説明
```
