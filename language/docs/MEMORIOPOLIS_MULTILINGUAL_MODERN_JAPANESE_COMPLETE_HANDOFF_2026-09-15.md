## 6．MEMORIOPOLIS型トレーニングの現在地

実際の通勤電車と空き時間で、次の使い分けが成立している。

### 急いでいるとき

```text
文字を見る
↓
音を聞く
↓
概念へ戻る
↓
次のカードへ進む
```

フラッシュカード的に高速で回す。

### 時間があるとき

```text
意味の橋を読む
音の橋を読む
文の組み立てを見る
用法や概念の境界まで確認する
```

同じカードが、短時間の高速訓練と、長時間の精読訓練の両方に対応する。

### 現在確認できている手応え

- Concept IDが固定軸になるため、言語がランダムに切り替わっても散漫にならない。
- 意味の核を維持したまま、文字、音、文法、語順だけが切り替わる。
- 「とっ散らからないランダム性」が生まれている。
- 臺灣華語は、繁體字、注音符號、拼音、声調の組み合わせがパズルとして機能する。
- `的 de`などの関係語が、節や名詞句を組み立てる連結部品として見え始めている。
- 英語は既知の言語であり、他言語の間の認知的な休息駅として働く可能性がある。

この方式の暫定定義：

> Concept IDで意味を固定し、言語面をランダムに切り替えることで、文脈を失わずに知覚と関係の再構成を促す多言語学習方式。

短く表すと、次の二行になる。

```text
概念は固定。
観測面はランダム。
```

## 10．近代日本語版の位置づけ

歴史にIfはない。

しかし、近代日本語版は次のような想像上の時間線を開く。

```text
もし明治・大正の文字文化が、
そのまま現代まで連続していたら。
```

これは歴史再現を断定するものではない。

また、戦前の日本語を忠実に復元する学術校訂版でもない。

```text
現代の制度
現代の技術
人工知性
画面
通知
識別子
権限
検証
```

を、歴史的仮名遣いと旧字体による別の時間層から観測する創作上の版である。

> 過去の物語ではなく、現在の記憶都市が別の文字史を通って表示された版。

この位置づけを維持する。

## 13．JANUS-13と本文

JANUS-13では、その節や文章を動かした一文を、一つのランダムな言語面で表示する。

```text
Novel
→ 物語の流れを決めるセリフ

Essay
→ 思考を動かす問い、主張

Commentary
→ 観測を始める事実またはコメント

Technical Reflection
→ 技術と制度を接続する命題

Research Paper
→ 中心仮説、定義、数式
```

一文そのものをクリックすると、その言語の本文へ進む。

13言語すべての本文を用意する必要はない。

一度の訪問で13面すべてを見せる必要もない。

```text
13面すべてが存在する
≠
13面すべてを同時に見せる
```

アクセス記録は作者だけが観測する。

人気ランキング、いいね、公開閲覧数競争には使わない。

```text
公開するが、競争させない。
観測するが、評価しない。
```

## 14．全13言語のAnki Core

本文は全13言語で作成しなくてよい。

しかし、Anki Coreは全13言語で作成する。

```text
本文
→ テーマと必要性に応じた言語だけで運行

Anki Core
→ 全13言語で整備
```

これは公開規模を増やすためではない。

篠原康秀を多言語クリエイターへ変える内部基盤として行う。

```text
現代日本語で概念を定める
↓
全13言語のCoreとして展開する
↓
意味の橋を作る
↓
音の橋を作る
↓
各言語の関係・文字・音を観測する
↓
親デッキMEMORIOPOLISで反復する
↓
差異が意識下へ蓄積する
↓
次の文章へ現れる
```

多言語クリエイターの暫定定義：

> 13言語すべてで同じ文章を書く人ではなく、テーマに応じて列車を選び、複数の言語面から車窓を観測し、その差異を次の文章へ蓄積できる人。

## 16．意味の橋と音の橋による不可視の研磨

文章を磨く理論や☆型は、今後、表へ出さない。

意味の橋と音の橋を作り、読み、反復すること自体が、日本語を磨く研磨剤となる。

```text
外国語を観測する
↓
意味の橋を読む
↓
音の橋を渡る
↓
別の言語へ移る
↓
現代日本語へ戻る
↓
変化が意識下へ蓄積する
```

乗客は、日本語を磨くために機関庫行きの列車へ乗るのではない。

意味と音を観測した結果として、乗客の内部に変化が残る。

ただし、変化が起きた瞬間や原因は特定できない。

```text
韓国語の助詞だったのか。
ロシア語の格だったのか。
臺灣華語の語順だったのか。
英語の冠詞だったのか。
近代日本語の字体だったのか。
反復の全体だったのか。
```

本人には分からない。

> 文章は磨かれた。だが、誰が磨いたのかは記録されていない。


### TTS

歴史的仮名遣いや旧字体をOSの日本語TTSへ直接渡すと、意図しない読みになる可能性がある。

そのため、TTSには現代読み用のフィールドを渡す構成を第一候補とする。

```html
{{tts ja_JP:ModernReading}}
```

例文も、必要に応じて現代読み用フィールドを設ける。

歴史的な復元発音は今回の目的にしない。
