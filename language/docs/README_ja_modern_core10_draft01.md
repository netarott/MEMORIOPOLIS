# MEMORIOPOLIS 近代日本語版 Core10 draft01

## 位置づけ

第四章第十二節の現代日本語正本と近代日本語版を結ぶ、日本語内部の垂直軸のAnki編成。
戦前期の口語文を想定し、歴史的仮名遣いと旧字体を表示する。文語文法や歴史的発音の復元は目的としない。

`MEMORIOPOLIS::ModernJapanese`
