# MEMORIOPOLIS Brazilian Portuguese Core10 draft01

## Variety
Português do Brasil, Windows locale `pt-BR`, Anki locale `pt_BR`.

## Deck
`MEMORIOPOLIS::Portuguese`

## Note type
`MEMORIOPOLIS Portuguese Vocabulary`

## Import
Import `pt_br_core10_anki_draft01_18fields.csv` as UTF-8, no header, 18 columns.

## TTS
```html
{{tts pt_BR:Portuguese}}
{{tts pt_BR:ExamplePortuguese}}
```

Windows Basic and TextToSpeech for pt-BR are installed.

## Daily Training
After import, rebuild `MEMORIOPOLIS Daily Training`. The first filter collects due cards and the second filter collects up to 10 new cards.

## AnkiDroid
If `pt_BR` does not resolve, temporarily add `{{tts-voices:}}`, copy the exact locale and voice identifier generated by AnkiDroid, and use them without normalization.
