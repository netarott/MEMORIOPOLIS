## インポート
1. ノートタイプを18フィールドで作成する。
2. Anki用CSVはヘッダーなし、UTF-8 BOM付き。
3. フィールドを順番どおりに割り当てる。
4. デッキを MEMORIOPOLIS::German に指定する。
5. タグ欄をCourseTagsに割り当てる。
6. TTSと表示を実機確認する。

## 品質方針
IPAはドイツ標準発音の学習用近似値。地域差、特にrの実現には幅がある。日本語訳はConceptの核を保ちつつ、ドイツ語の性・格・語順・複合語を観測できる形にした。
