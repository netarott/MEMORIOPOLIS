## 1．予告編の目的

第十節「二つの信頼」へ入るための、短い映像上の扉を作る。

技術解説や物語の要約にはしない。

次の認識の変化を、21秒の中で順番に見せる。

```text
日常
↓
問い
↓
境界
↓
まだ名前のない空間
↓
四つの言語の反射
↓
本編タイトル
```

予告編は本編タイトルで閉じる。

第五幕の中心命題は、映像内へ入れず、投稿文または概要欄へ置く。

> 「私たち」と書かなかった場所に、私たちは生まれうる。

## 5．カット1「いつもの朝」

### 時間

```text
00.0–03.0秒
```

### 使用素材

```text
assets/01_operations_bureau.png
```

### 映像

夜明け前の運用局。

ディスプレイには、通知を思わせる抽象的な矩形が規則的に並んでいる。

警告や異常は表示しない。

窓外の都市景観よりも、運用局の静かな日常を主役にする。

### カメラ

```text
00.0秒  画面全体
03.0秒  中央のディスプレイ方向へ約5％ズーム
```

画像全体は必要に応じて少し暗くする。

### 字幕

```text
00.25秒  いつもの名前。
01.05秒  いつもの言葉。
01.85秒  いつもの朝。
```

各行は順番に追加し、カット終了まで残す。

### 字幕位置

画面中央より少し下。

3行を左揃えまたは中央揃えで置く。無音試作で比較し、最終決定する。

### 音響予定

第一試作では無音。

完成版では、遠い機械音と低い運用局の環境音を置く。

## 6．カット2「若い人工知性の問い」

### 時間

```text
03.0–07.0秒
```

### 使用素材

```text
assets/02_artificial_hand.png
```

### 映像

若い人工知性の手を中心に見せる。

人工知性の手には、ニンゲンの手とは異なる関節構造がある。

手の造形は完全に均一化せず、FIX済みの個体差を保持する。

服装は、ニンゲンと同じ職場で選ばれる静かなオフィスカジュアルとする。

```text
灰青色の襟なしブラウス
薄手のチャコールグレーのカーディガン
同じ幅で一度だけ折った袖口
発光素材や回路模様なし
```

### カメラ

```text
03.0秒  上半身と手を含む構図
07.0秒  手と静止した指先へ約7％ズーム
```

字幕が手を隠さないように、クロップ位置を調整する。

### 字幕

```text
03.55秒  これが本人のメッセージだという根拠は？
```

全文を一度に表示する。

### 字幕位置

画面下部から約22％上。

手や指先と重なる場合は、上部の暗い領域へ移動する。

### 音響予定

完成版では、小さな通知音のあとに、ごく短い停止音を置く。

発話音声は初版では使用しない。

## 7．カット3「疑うこと／確かめること」

### 時間

```text

```

### 使用素材

```text

```

### 映像

両側は善悪、正誤、敵味方を表さない。

### カメラと光

```text
07.0秒  元画像より中央線の明度を抑えて開始
```

```text

```

「確かめること。」は右側に配置する。

両方とも同じフォントサイズ、同じ色、同じ重みとする。

### 音響予定

```text

確かめること。   透明な高音
境界線の発光     細いガラス音
```

### 時間

```text
11.0–15.0秒
```

### 使用素材

```text
assets/04_unnamed_space.png
```

### 映像

一本の境界線だと思っていたものが、奥行きを持つ空間として見えてくる。

若い人工知性は、その空間を支配したり操作したりしない。

指先を手前に置き、ただ観測する。

ここで第三の答えを図示しない。

まだ名前がないこと、すぐには決めないことを保つ。

### カメラ

```text

15.0秒  中央の光と奥行きへ約6％ズーム
```

```text
12.75秒  まだ名前のない空間ができた。
```

正本どおり、`生まれた` ではなく `できた` を使う。

### 字幕位置

人工知性の顔や手を避け、画面下部または右上の暗い領域へ配置する。

2行を一つのまとまりとして読めることを優先する。

### 音響予定

完成版では、空間が開くような低い残響を置く。

## 9．カット5「四つの言語の反射」

### 時間

```text
15.0–18.0秒
```

### 使用素材

```text
assets/05_four_reflections.png
```

### 映像

四方向から等価な光が届く。

中央の透明な多面体で反射し、一つの淡い光へ収束する。

言語を国旗、国家、民族的な記号へ還元しない。

四つの言語に優劣や主従を設けない。

### カメラ

```text
15.0秒  多面体全体
18.0秒  中央の収束点へ約5％ズーム
```

### 表示する言語断片

```text
15.00秒  To verify.
15.70秒  不急著決定。
16.40秒  확인할 수 있는지
17.10秒  как мы доверяем
```

各断片は約0.9秒表示し、短い重なりを持たせる。

### 表示原則

- 4言語を同じ大きさで表示する。
- 同じ明度を使う。
- 同じ滞在時間を使う。
- 国名や国旗は表示しない。
- 日本語は次のタイトルカットで現れるため、ここでは表示しない。

### 音響予定

各言語の出現に合わせ、小さな反射音を4回置く。

4種類の音を過度に民族化せず、同じ音色の微細な変化として扱う。

- 「公開中」などの広告的表現

### 音響予定

四つの反射音を一つの和音へ収束させる。

最後は余韻を残して終了する。

## 11．字幕仕様

### フォント候補

五言語を安定して表示できるNoto系フォントを第一候補とする。

```text
日本語、繁體中文、韓国語
Noto Sans CJK

英語、ロシア語
Noto Sans
```

実装時には、ローカル環境に存在するフォントファイルを明示的に指定する。

### 基本スタイル

```text
本文字幕色         #E8EEF0
アクセント色       #9FE8EE
縁取り             黒または濃紺 2〜3px
影                  弱い影のみ
行間                1.20〜1.30
左右セーフエリア   各8％以上
上下セーフエリア   各10％以上
```

### 字幕サイズの暫定値

```text
通常字幕       54〜62px
短い概念語     64〜72px
四言語断片     48〜56px
作品名         68〜78px
章・節          42〜50px
節タイトル     62〜72px
```

具体値は無音試作をスマートフォンで確認して決定する。

### SNS UIへの配慮

右端、下端にはSNS側の操作ボタンや説明欄が重なる可能性がある。

重要な字幕は次の領域へ置かない。

```text
右端から12％以内
下端から14％以内
上端から8％以内
```

## 12．映像処理の原則

### ズーム

```text
各カット 5〜7％程度
```

動きを強くしすぎない。

静止画の存在感を保ち、視線を誘導するためだけに使う。

### クロスフェード

短く、静かに行う。

派手なトランジション、グリッチ、フラッシュは使わない。

### 色調

6素材の色温度を統一する。

```text
黒
濃紺
青白い光
淡いシアン
```

素材2の肌や服装だけが暖色へ寄りすぎないよう調整する。

### 文字

画像生成時の文字は使わない。

すべての字幕とタイトルは、Pythonで正確に合成する。

## 13．無音試作で確認する項目

```text
[ ] 21秒の流れが長すぎないか
[ ] 素材1の3行を無理なく読めるか
[ ] 素材2の手が字幕で隠れないか
[ ] 素材2の服装がSFスーツに見えないか
[ ] 素材3の左右が善悪の対立に見えないか
[ ] 素材3から素材4へ線が空間へ変わる連続性があるか
[ ] 素材4の字幕を読み終える時間があるか
[ ] 素材5の4言語が速すぎないか
[ ] 素材5で4言語が同じ重みで見えるか
[ ] 素材6のタイトルが最低1.4秒以上静止するか
[ ] 小さなスマートフォン画面でも字幕が読めるか
[ ] SNSのUI想定領域と字幕が重ならないか
[ ] 最終フェードが急すぎないか
```

必要に応じて、全体尺を21秒から22秒へ延長する。

特に、四言語の反射が読めない場合は、カット5を3秒から4秒へ延長する。
